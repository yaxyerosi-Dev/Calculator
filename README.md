# Calculator App

A simple and responsive calculator built using HTML, Tailwind CSS, and JavaScript.

## Features

- Basic arithmetic operations
- Responsive design
- Modern UI using Tailwind CSS
- External JavaScript functionality
- Clear and delete buttons
- Error handling

---

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript

## How It Works

### HTML

The HTML file creates:

- Calculator layout
- Buttons
- Display screen

### Tailwind CSS

Tailwind CSS is used for:

- Colors
- Spacing
- Responsive design
- Hover effects
- Styling buttons

### JavaScript

JavaScript handles:

- Displaying numbers
- Operators
- Clearing screen
- Deleting last character
- Calculating results
